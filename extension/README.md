# Lecture Dub YouTube Extension

YouTube의 실제 시청 페이지에서 로컬 한국어 더빙 WAV와 영어·한국어 VTT를 영상 시간에 맞춰 재생하는 Chrome/Edge 확장 프로그램입니다.

외부 임베드가 차단된 영상도 YouTube 자체 페이지에서는 정상적으로 볼 수 있으므로, 별도 iframe 플레이어 대신 이 확장 프로그램을 사용할 수 있습니다.

> 이 확장 프로그램은 YouTube의 접근 제한이나 유료·비공개 콘텐츠를 우회하지 않습니다. 사용자가 원래 YouTube에서 시청할 수 있는 영상의 `<video>` 재생 시간에 로컬 파일을 맞춰 재생할 뿐입니다.

## 설치

1. 저장소를 내려받거나 clone합니다.
2. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누릅니다.
5. 이 저장소(lecture-dub)의 `extension/` 폴더를 선택합니다.

스토어 배포 전까지는 위 방식으로 설치합니다.

## 사용법

1. YouTube에서 원하는 강의를 평소처럼 엽니다.
2. 화면 오른쪽 아래의 **Lecture Dub** 버튼을 누릅니다.
3. 생성한 한국어 WAV를 선택합니다.
4. 필요하면 한국어 VTT와 영어 VTT도 선택합니다.
5. **더빙 시작**을 누릅니다.
6. 이후에는 YouTube의 재생·일시정지·탐색·배속을 그대로 사용합니다.

한국어 WAV는 필수이고 자막은 선택 사항입니다.

## 동기화되는 항목

- 재생 / 일시정지
- 영상 탐색(seek)
- 재생 속도
- 현재 시간
- 0.1초 단위 수동 싱크 보정

기본적으로 YouTube 원음은 음소거하며, 패널에서 다시 기존 상태로 돌릴 수 있습니다. 더빙 음량도 별도로 조절할 수 있습니다.

## 파일 처리

WAV와 VTT는 사용자의 브라우저 탭에서 `File`/`Object URL`로 읽습니다. 선택한 파일을 GitHub나 Lecture Dub 서버로 업로드하지 않습니다.

## YouTube에서 새 영상으로 이동할 때

YouTube는 페이지 전체를 새로고침하지 않고 다음 영상으로 이동하는 경우가 많습니다. 확장 프로그램은 이를 감지해 기존 더빙을 자동으로 끕니다. 새 영상에 맞는 파일인지 확인한 뒤 **더빙 시작**을 다시 누르세요.

## 현재 범위

- Chromium 기반 Chrome/Edge용 Manifest V3 확장 프로그램입니다.
- YouTube DOM 구조가 크게 변경되면 플레이어 탐지 로직의 수정이 필요할 수 있습니다.
- 확장 프로그램 자체에서 번역이나 TTS를 생성하지는 않습니다. `lecture-dub` CLI/Web UI로 만든 WAV/VTT를 사용합니다.
